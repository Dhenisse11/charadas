# El reto de las Señas Saladas · Sal Celestial

Juego de charadas de una sola página (HTML, CSS y JS sin dependencias). Funciona sin internet una vez cargado.

- Retos y premios: se editan en `index.html`, arrays `RETOS`, `GANA` y `PIERDE`.
- Tiempo por ronda: variable `T` (30 segundos).
- Instagram: @salcelestial
